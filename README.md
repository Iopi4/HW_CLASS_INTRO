Задание 2 (НЕобязательное)
В класс книги теперь автор должен передаваться и храниться как объект класса Author. 
Метод matches должен проверять не только по имени автора, но и по фамилии. 
Цена книги теперь рассчитывается как 3 рубля за страницу, умноженное на квадратный корень из рейтинга, после чего округлённое вниз, но не меньше 250 рублей.
